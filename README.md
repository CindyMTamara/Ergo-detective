# ErgoDetective

Juego web interactivo para identificar riesgos ergonómicos en tres escenarios: oficina, manipulación de cargas y línea de empaque.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `script.js` a la raíz.
3. Abre **Settings > Pages**.
4. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)**.
5. Guarda.

## Incluye
- 3 misiones y 12 riesgos.
- Tiempo, vidas, puntuación, pistas y precisión.
- Retroalimentación educativa inmediata.
- Diseño responsive.
- HTML, CSS y JavaScript puro, sin dependencias.

El juego es material educativo general. Las medidas y cambios reales de puesto deben validarse con el equipo de Seguridad y Salud en el Trabajo y mediante evaluación del trabajo específico.
